Raspberry Pi 5 Setup Guide

Target: RoArm-M3 (WiFi) + SO-101 (USB/serial) + Camera

1. OS Installation

Flash Raspberry Pi OS

  1. Download Raspberry Pi Imager
  2. Select Raspberry Pi 5 and Raspberry Pi OS (64-bit)
  3. Choose your SD card (8GB+ recommended)
  4. Click Next, select Edit Settings:
    • Set hostname (e.g., alien-bazaar)
    • Enable SSH (password auth OK for now)
    • Set WiFi SSID and password
    • Set timezone
  5. Write and wait ~5 min

First Boot

ssh pi@alien-bazaar.local
# Password: raspberry (default)
sudo raspi-config
# → System Options → Boot → Console (headless is fine)
# → Interfacing Options → Camera (if using CSI) / Serial (for SO-101)
sudo reboot
Note: If you're using CSI camera, enable it in raspi-config. For USB camera, no config needed.

2. System Setup

Update and Install Base Tools

sudo apt update && sudo apt upgrade -y
sudo apt install -y python3-pip python3-venv git
sudo apt install -y libatlas-base-dev libjasper-dev libharfbuzz0b libwebp6 libopenjp2-7
# ↑ These are for camera/CV libraries

Create Virtual Environment

mkdir -p ~/alien-bazaar
cd ~/alien-bazaar
python3 -m venv venv
source venv/bin/activate

3. Install Dependencies

Core Libraries

# Camera (PiCamera2 is the modern standard for RPi 5)
sudo apt install -y python3-picamera2
pip install --upgrade pip

# Serial/USB communication (for SO-101)
pip install pyserial

# RoArm-M3 (assumes they use Python library; if not, note their SDK)
pip install roarm
# or if you have a custom SDK: pip install /path/to/roarm-sdk

# Optional: numpy, OpenCV if doing image processing
pip install numpy
# opencv-python takes ~20min on RPi; install only if needed
RoArm-M3 Note: Check if RoArm has an official Python package. If not, you may need to use their API docs and write a simple socket/HTTP client. Confirm this before proceeding.

4. Test SO-101

Identify USB Device

lsusb
# Look for SO-101 in the list, note the USB ID

Test Serial Connection

python3 << 'EOF'
import serial
import time

# Find the device (usually /dev/ttyUSB0 or /dev/ttyACM0)
port = "/dev/ttyUSB0"  # Adjust if needed
baud = 115200           # Check SO-101 docs for correct baud rate

try:
    ser = serial.Serial(port, baud, timeout=1)
    print(f"✓ Connected to {port} @ {baud} baud")

    # Send a simple test command (adjust to SO-101 protocol)
    ser.write(b"TEST\r\n")
    response = ser.readline()
    print(f"Response: {response}")
    ser.close()
except Exception as e:
    print(f"✗ Error: {e}")
    print("  Check: device is plugged in, baud rate, and permissions")
EOF
Permission Issue? If you get permission denied, run: 
sudo usermod -a -G dialout pi
# Then log out and back in

5. Test RoArm-M3 (WiFi)

Find RoArm IP on Network

nmap -sn 192.168.1.0/24 | grep -i roarm
# or: ping roarm.local (if it broadcasts mDNS)

Test Connection

python3 << 'EOF'
# Adjust imports/API based on RoArm SDK you have
try:
    from roarm import RoArm
    arm = RoArm(ip="192.168.1.XXX")  # Replace with actual IP
    arm.connect()
    print("✓ RoArm-M3 connected")
    # Test a safe move (e.g., home position)
    arm.go_home()
    print("✓ Home command sent")
except Exception as e:
    print(f"✗ Error: {e}")
EOF
RoArm WiFi latency: Expect 10–50ms control lag. Not suitable for force-feedback, fine for pick-and-place.

6. Test Camera

PiCamera2 (Recommended for RPi 5)

python3 << 'EOF'
from picamera2 import Picamera2

try:
    cam = Picamera2()
    config = cam.create_preview_configuration()
    cam.configure(config)
    cam.start()
    print("✓ Camera initialized")

    # Capture a frame
    frame = cam.capture_array()
    print(f"  Frame shape: {frame.shape}")
    cam.stop()
except Exception as e:
    print(f"✗ Error: {e}")
EOF
CSI vs USB: CSI ribbon camera is faster (~30fps native). USB camera is ~10fps but works on any USB port. Choose based on your hardware.

7. Minimal Controller Script

Create ~/alien-bazaar/controller.py:

#!/usr/bin/env python3
import threading
import time
from picamera2 import Picamera2
import serial

class SO101Controller:
    def __init__(self, port="/dev/ttyUSB0", baud=115200):
        self.ser = serial.Serial(port, baud, timeout=1)

    def send_command(self, cmd):
        self.ser.write(cmd.encode() + b"\r\n")
        return self.ser.readline()

class RoArmController:
    def __init__(self, ip):
        # Initialize based on your RoArm SDK
        self.ip = ip
        # self.arm = RoArm(ip=ip)

    def move_home(self):
        pass  # Implement based on SDK

class CameraController:
    def __init__(self):
        self.cam = Picamera2()
        self.cam.configure(self.cam.create_preview_configuration())
        self.cam.start()

    def capture(self):
        return self.cam.capture_array()

# Main coordinator
def main():
    so101 = SO101Controller()
    roarm = RoArmController(ip="192.168.1.XXX")
    camera = CameraController()

    print("✓ All systems initialized")

    # Example workflow
    try:
        frame = camera.capture()
        print(f"  Captured frame: {frame.shape}")
    except Exception as e:
        print(f"✗ Camera error: {e}")

if __name__ == "__main__":
    main()

8. Autostart (Optional)

Run controller on boot via systemd:

sudo tee /etc/systemd/system/alien-bazaar.service > /dev/null << 'EOF'
[Unit]
Description=Alien Bazaar Controller
After=network.target

[Service]
Type=simple
User=pi
WorkingDirectory=/home/pi/alien-bazaar
ExecStart=/home/pi/alien-bazaar/venv/bin/python3 controller.py
Restart=on-failure

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable alien-bazaar
sudo systemctl start alien-bazaar
sudo systemctl status alien-bazaar
